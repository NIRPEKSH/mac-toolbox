# Optimize Memory

Scripts to free up disk space on your Mac — without losing what matters.

> Running low on storage? Before you buy an external drive or delete things you'll regret, try these scripts.

---

## Why this matters

Macs (especially the base models) come with limited SSDs — 256 GB or 512 GB fills up fast. Most of that space is eaten by media files, caches, and duplicates that can be optimized without any visible quality loss.

---

## Scripts

| Script | What it does | Typical savings |
|---|---|---|
| [Video Compression](video-compression/) | Re-encodes videos to H.265/HEVC — same quality, ~50-60% smaller | 4+ GB on a folder of 1080p videos |

---

## How these scripts stay safe

Every script in this category follows these rules:
- **Originals are never deleted** — they're moved to a backup folder
- **You verify first** — check the output, then delete originals yourself
- **Disk space is checked** before starting, so you don't run out mid-process
- **Progress is reported** so you know what's happening and how long it'll take
